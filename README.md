# 💻 Односторінковий сайт-портфоліо учня 8-Д класу

Простий, легкий та компактний односторінковий сайт (Landing Page), створений на швидку руку як практичний прототип для демонстрації захоплень, улюблених ігор та базових навичок учня. Проєкт виконано в мінімалістичному темному стилі з яскравими помаранчевими акцентами.

---

## 🛠 Особливості реалізації & Швидка верстка

Головна мета проєкту — максимально швидко зібрати робочий та адаптивний інтерфейс, використовуючи базовий стек технологій без ускладнень:

* **Формат Односторінника** — уся інформація компактно розміщена на одній сторінці. Навігація між розділами («Захоплення», «Про мене», «Ігри», «Контакти») реалізована за допомогою швидких внутрішніх посилань-якорів.
* **Простий HTML5 & CSS3** — чиста семантична розмітка та базові стилі без важких сторонніх бібліотек чи фреймворків.
* **Верстка на Flexbox** — усі блоки та сітки карток вирівняні за допомогою Flexbox, що дозволило оперативно налаштувати структуру сайту.
* **CSS змінні (`var`)** — палітра кольорів винесена в глобальні змінні для зручності, щоб можна було в один клік змінити тему сайту.
* **Вбудований SVG-код** — замість завантаження окремих картинок-іконок для захоплень, використано легкий вбудований SVG-код, що спрощує структуру та прискорює відображення сторінки.
* **Відносні посилання** — для кнопок переходів використано локальні шляхи, щоб за потреби сайт можна було так же швидко масштабувати.

---

## 📱 Адаптивність «на швидку руку» (Responsive Design)

Для того, щоб односторінник адекватно виглядав на мобільних пристроях, було додано прості медіа-запити (`@media`):

1. **Десктоп:** Стандартна сітка карток по 3 штуки в ряд для великих екранів.
2. **Планшети:** Шапка переходить у вертикальний формат (логотип і меню одне під одним), зберігаючи три картки в ряд.
3. **Мобільні телефони:** 
   * Складні сітки карток спрощуються і шикуються в один стовпчик на всю ширину екрана (`100%`).
   * Контакти в підвалі падають один під одного для зручного тапу.
   * Навігаційне меню перетворюється на горизонтальну лінію, яку можна просто гортати пальцем вбік (скролити), що економить місце на екрані.
